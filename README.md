# Everyday Things, Two Lines, Longer Run

A make.fun bounty entry: a small program that explains one everyday thing
to a 10-year-old in exactly two lines — one vivid analogy, then an honest
note on what the analogy maps and what it leaves out — written to
`/output/entry.txt`.
